## What to build

Homing goes back to NEC's procedure (ADR 0010): a pre-home move off the switch if needed, then `SP 900`, `HM`, `BG`, twice, and zero at the second stop if the two stops agree within 4 counts.

1. **`AxisHomeRoutine`** (`galil_workers.py`):
   - `run() -> (ok, message)`, no arguments, never raises. Pass 1 = `pre_home_move()` then `home_move(SC.HOMING_SPEED_COUNTS_PER_SEC)`; pass 2 = the same again; then the agreement check; on success `define_zero(axis)` then `define_encoder_zero(axis)`. `_restore_speeds()` runs in a `finally` on success and failure. An exception becomes `"<axis>: homing error — <e>"`, as today.
   - New `pre_home_move() -> (ok, message)`: on the forward limit, no move, success. Home switch and reverse limit both clear: no move, success. Otherwise `set_speed(axis, SC.DEFAULT_SPEED_COUNTS_PER_SEC)`, one `move_relative(axis, SC.PRE_HOME_MOVE_COUNTS)`, `wait_idle(timeout=15.0)` (timeout → `"<axis>: timeout in the pre-home move"`), then both switches must read clear, else fail with `"<axis>: still on the home switch after the pre-home move of 2000 counts — zero not set"` (2000 from the constant).
   - New `home_move(speed) -> (ok, message, stop_position | None)`: if the home switch already reads tripped, fail `"<axis>: on the home switch before the home move — run the pre-home move first"` without sending anything. Otherwise `set_speed(axis, speed)`, `galil.home(axis)`, sleep `_SEEK_SETTLE_S`, then poll `is_moving` every `_SEEK_POLL_S`: cancel → `stop(axis)`, fail `"<axis>: cancelled during the home move"`; past `SC.HOME_SEEK_TIMEOUT_S` → `stop(axis)`, fail `"<axis>: timed out after 180 s in the home move"` (180 formatted from the constant with `:.0f`). Once stopped, `wait_at_rest(timeout=15.0)` (failure → its message, prefixed `"<axis>: "`), and only then read the switches, `get_stop_code` and `get_position`. Accept only home switch tripped and stop code in `SC.HOME_ACCEPTED_STOP_CODES`. Failures: reverse tripped with home clear → `_reverse_msg(axis)`; neither tripped → `"<axis>: home move stopped before reaching the home switch (stop code N)"`; home tripped, other code → `"<axis>: home move ended with stop code N — zero not set"`. Requirement: every switch and stop-code read happens after `wait_at_rest`, because a read while pulses are still going out is the failure ADR 0010 guards against.
   - Agreement: `abs(stop2 - stop1) > SC.HOME_STOP_AGREEMENT_COUNTS` → `"<axis>: home stops disagree — pass 1 at S1 cts, pass 2 at S2 cts (limit 4) — zero not set"`. Progress after each pass: `"<axis>: pass k/2 — stopped at S cts"`. Success: `"<axis>: homed — stops S1, S2 cts, DP=0 at pass 2"`.
   - Remove `seek_home_limit` and `home_passes`.
   - **Keep for now, unchanged:** `back_out_of_home` (the switch map uses it permanently; the edge-return test until 178), `approach`, `creep_to_release` and the constructor's `approach_speed` argument (the edge-return test still uses them; ticket 178 removes them). `run()` must never read `approach_speed`. Update their docstrings to say who still calls them.
   - Constants (`hardware_config.py`): remove `HOME_PASS2_BACKOFF_COUNTS`. Keep `HOME_START_BACKOFF_COUNTS` and `HOME_START_BACKOFF_TRIES` (the switch map's back-out uses them; comment that). `HOME_EDGE_AGREEMENT_COUNTS` stays until 177 rewrites the Auto-Home texts that use it.
2. **Workers:** `HomingWorker(galil, axis, parent=None)` and `AutoHomeAllWorker(galil, axes=None, parent=None, stop_on_failure=True)`. Their `seek_first` and `approach_speed` arguments and attributes go. They call `AxisHomeRoutine(galil, axis, progress=…, cancelled=…).run()`. Docstrings describe `HM` homing.
3. **`AxisControls`** (`motor_tab.py`): remove `btn_seek_home` and every reference to it (the home row, both control lists, `_start_homing`, `_reset_home_buttons`). `btn_home` stays labelled `Home <axis>`, connects to `self._start_homing()` (no arguments) and has the tooltip `f"Moves the axis off its switch if it is on one ({SC.PRE_HOME_MOVE_COUNTS} counts at {SC.DEFAULT_SPEED_COUNTS_PER_SEC} cps), then homes with HM at {SC.HOMING_SPEED_COUNTS_PER_SEC} cps twice and zeroes at the second stop if the two stops agree within {SC.HOME_STOP_AGREEMENT_COUNTS} counts."`. `_start_homing` logs `# Starting auto-home for axis <axis>…`, shows `Homing…`, sets `btn_home` to `Cancel` and builds `HomingWorker(g, self.axis, self)`. Cancel and lock behaviour is unchanged.
4. **`MotorTab._start_auto_home`:** `AutoHomeAllWorker(self.galil, SC.AXIS_LETTERS, self)` (no approach speed). Its texts change in ticket 177.
5. Module and class docstrings that describe the seek or release-edge homing describe `HM` homing instead.
